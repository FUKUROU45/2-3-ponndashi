# 2-3-ponndashi

`index.html` の `SOUND_CONFIG` に登録したMP3を、ボタンから再生するポン出しアプリです。
HTMLと `audio/` フォルダを同じ場所に置いて使用します。ビルドや外部ライブラリは不要です。

## 音源の追加方法

1. MP3を `audio/` に配置します。
2. `SOUND_CONFIG` に、重複しない `id`・表示名 `label`・相対パス `file`・色 `color`・表示順 `order` を1件追加します。
3. ブラウザで新しいボタンの再生、別の音への切り替え、「すべて停止」を確認します。

## 音源が増えたときの画面

通常は縦向き2列・横向き4列です。狭い画面では幅に合わせて列数を調整します。
ボタンは高さ88px以上を保ち、収まらない場合は音源一覧だけを縦スクロールできます。
「すべて停止」は一覧の外にあるため、スクロールしても上部から操作できます。

## オフライン利用について

このリポジトリにはService Workerやオフラインキャッシュは含まれていません。
GitHub Pagesで公開するだけではオフライン動作は保証されません。
iPad内のファイルで使う場合は、HTMLと音源フォルダを扱えるローカルHTML実行アプリで開いてください。
